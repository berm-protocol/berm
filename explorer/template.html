How this decides

Self-declared dates prove nothing. Any key can sign an event dated 2009. Most Nostr tooling displays created_at as though it were a fact — which is exactly how a squatter wins an argument they should lose.

Priority therefore comes from an external anchor: an OpenTimestamps proof placing the claim at a Bitcoin block height nobody can backdate. Unanchored claims are still shown, but they can never outrank an anchored one, and if nothing is anchored this page refuses to name a winner.

Handles recycle; numeric X ids never do. A claim bound only to a handle cannot distinguish the original owner from whoever registered it afterwards. That is why the account id matters more than the name.

This page is a lens, not a source. The claims live on relays whether it runs or not. If it disappears, nothing is lost. If it lies, the raw events are one click away and anyone can catch it.
