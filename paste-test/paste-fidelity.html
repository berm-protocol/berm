X Article paste fidelity

The free publishing path depends on one unknown: how much formatting survives a paste into X's Article editor. Five minutes here answers it, and the answer decides whether API access is optional or required.

—
How to run it
  1. Click Copy as rich text. This puts HTML on the clipboard, with markdown as the plain-text fallback.
  2. Open X and start a new Article (you need Premium). Paste into the body.
  3. Work down the table below and mark what survived. The specimen is ordered to match.
  4. Export result and keep it — this is the evidence that decides the publishing path.
  5. Optionally repeat with Copy markdown only to confirm the difference. Expect it to arrive as literal ## characters — rich-text editors don't interpret markdown.
What each outcome means

Most things survive. The free path is real. Ship "copy for X" as the default and treat the API as a convenience upgrade. No developer approval on the critical path.

Text survives, images don't. Still fine — paste, then add images by hand in X. Say so in the UI so nobody is surprised.

Structure collapses. The free path is a bad experience and the draft-via-API route becomes necessary rather than optional. That makes X developer access a blocker, and it should move to the top of the list today.
